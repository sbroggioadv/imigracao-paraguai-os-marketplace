# imigracao-paraguai-os-marketplace

Marketplace oficial do plugin **imigracao-paraguai-os** (IA Combativa).

## O que é

Sistema operacional de imigração para o **Paraguai** — 3 frentes (imigrante · comercial · advogado). 44 skills, Ley 6984/2022, gates de vigência e de representação (OAB ≠ matrícula PY).

## Instalação (Claude Cowork / Claude Code)

1. Abra **Settings → Plugins**
2. Aba **Pessoal** → **+** (Uploads locais / Add marketplace)
3. Cole a URL deste repositório GitHub
4. Instale o plugin `imigracao-paraguai-os`
5. Rode `/start-imigracao-paraguai` e depois `/imigracao-paraguai`

## Aviso

Este plugin **não substitui** advogado matriculado no Paraguai. Não garante residência, cédula, RUC ou naturalização.

O repositório é público para viabilizar a instalação. **Não é software livre** — o direito de uso é concedido pela compra (Kirvano). Ver `LICENSE`.
