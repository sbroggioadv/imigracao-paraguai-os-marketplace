## Travas que o mercado erra
- Lei vigente é a **6984/2022** (não a 978/1996; autoridade é a **DNM**, não DGM)
- OAB **não** representa perante a DNM
- Sem “job seeker / nômade / rentista” como visto temporário confirmado
- Sem depósito mágico; solvência = **Res. DNM 407/2026**
- Residência ≠ cédula ≠ RUC ≠ residência fiscal ≠ nacionalidade
- Naturalização conta da **permanente**, não da chegada
- Refúgio não regulariza projeto econômico
- Recurso **não** suspende sozinho
